# Dream Evolution Platform

A full-featured event management and company website developed for **Dream Evolution** using React and Firebase. The platform provides event management tools, artist management, user registration, contact forms, and an administrative dashboard, all within a modern and responsive web application.

## Project Overview

Dream Evolution is one of my largest and most advanced web development projects. The goal was to create a professional platform that allows users to explore events, register for activities, and connect with the organization, while providing administrators with tools to manage content efficiently.

## How to Run

1. Clone or download the repository.
2. Install dependencies:

```bash
npm install
```

3. Configure Firebase credentials if required.
4. Start the development server:

```bash
npm start
```

or

```bash
npm run dev
```

(depending on the project setup)

This project uses Firebase for storing game data. The original Firebase configuration is no longer active, so some online features (such as score storage or leaderboard functionality) may not work when running the project locally.

The game itself remains fully functional, and the code demonstrates the integration of Firebase services as part of the project's development.
